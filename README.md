# D&D 5e – Traduction FR – Manuel du Joueur

Module FoundryVTT (v13+) de traduction française du compendium officiel **Player's Handbook 2024** pour le système dnd5e.

## Dépendances

- Système : [dnd5e](https://foundryvtt.com/packages/dnd5e)
- Module requis : `dnd-players-handbook` (contenu officiel D&D)
- Module recommandé : [Babele](https://foundryvtt.com/packages/babele) (traduction automatique des compendiums)

## Installation

1. Copier le dossier `translation-PHB-fr` dans `[FoundryVTT Data]/modules/`
2. Activer le module dans les paramètres du monde
3. Activer également Babele si ce n'est pas déjà fait

## Contenu traduit

| Compendium | Fichier |
|---|---|
| Acteurs (PNJ) | `dnd-players-handbook.actors.json` |
| Classes | `dnd-players-handbook.classes.json` |
| Contenu général | `dnd-players-handbook.content.json` |
| Équipement | `dnd-players-handbook.equipment.json` |
| Dons | `dnd-players-handbook.feats.json` |
| Origines | `dnd-players-handbook.origins.json` |
| Sorts | `dnd-players-handbook.spells.json` |
| Tables aléatoires | `dnd-players-handbook.tables.json` |
